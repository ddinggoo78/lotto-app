# 로또 6/45 분석기 (핸드폰 앱)

당첨번호 통계, 번호 생성기(10개 조합 + 정밀 추천 5개), 고정·제외수 검증, 내 번호 조회를 핸드폰에서 쓰는 앱입니다.

- 앱 주소: https://ddinggoo78.github.io/lotto-app/
- 갤럭시: 크롬으로 열고 「앱 설치」(또는 ⋮ → 홈 화면에 추가 → 설치)
- 아이폰: 사파리로 열고 공유 → 홈 화면에 추가
- 당첨번호는 매주 토요일 밤·일요일·월요일 아침에 자동으로 업데이트됩니다 (`.github/workflows/update-data.yml`).

※ 어떤 조합이든 1등 확률은 1/8,145,060로 같습니다. 이 앱은 번호를 고르는 기준을 정리해 주는 도구입니다.
